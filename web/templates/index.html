Where this started

One half-term week in Cervinia

The project began with a trip to Cervinia over 14–22 February 2026 and a question: is it always like this? Collection started the day after, so the lift record never saw that week — but the weather record did. So far

What one season of records says

Early findings. One part-season is thin evidence, and each of these links to the chart it came from so you can judge it yourself.

Wind matters more at some resorts than others

Across all resorts the link between gusts and closures is weak. Split by resort it is not: some fall away sharply in wind while others barely move.

See it in the scatter lab →

Some mountains close in a fixed order

At Cervinia and Méribel the same lifts go first each time, which makes closures predictable lift by lift. At St Anton and Tignes they do not.

See the closure order →

Wind direction added nothing

Knowing which way the wind blew across each lift did not improve on gust speed alone. It is reported here as a null rather than left out.

The freezing level is climbing

At Cervinia in February half-term the estimated 0 °C line has risen by roughly 230 m a decade since 1991 (95% interval 63 to 395).
